# 4. What it costs

We model cost to serve in three layers. Layer 1 uses measured D5 input/output tokens at frozen prices; no paid retrieval or external tool fee was measured. Layer 2 is expected manual fallback cost: `(1 − success rate) × US$7.60`, representing twelve minutes of a claims assessor’s time at US$38 per hour. Layer 3 is fixed operating cost. With no production invoices, we use LI LINGHAO’s approved US$200/month prototype scenario across hosting, logs, monitoring, storage, regression and maintenance. It is an assumption, not measured spend.

DeepSeek v3.2 v2 has the lowest observed cost to serve. It passed 71 of 75 trials, giving 94.67% success. Layer 1 costs US$0.003771 per claim, but expected fallback adds US$0.405333. The total is US$0.409105 before Layer 3, or US$3,472.84 per month with the US$200 baseline. Qwen has the lowest token cost, US$0.000972 per claim, but its 14.67% success produces US$6.485333 of fallback cost and a US$52,090.44 monthly total. Claude Haiku 4.5 costs US$38,446.00 per month. Cheap tokens alone do not create a cheap system; reliability determines whether human handling overwhelms API savings.

Four cost levers support this conclusion. First, the shipped tool block is approximately 300 prompt tokens, but no measured before/after value exists, so no saving is claimed. Second, parallel calling reduced one trajectory from 13 to 4 turns, 19,283 to 7,505 tokens, and US$0.0041 to US$0.0017 while preserving the answer. This is single-case evidence. Third, direct observation-size measurements are unavailable. The paired DeepSeek v1/v2 batteries provide system-level evidence: v2 reduced turns by 3.77%, input tokens by 2.49%, output tokens by 7.32%, and agent spend by 2.93%, while success rose from 64/75 to 71/75. Fourth, success rate dominates: one percentage point is worth approximately US$608 per month at 8,000 claims.

Sensitivity analysis confirms the ranking. With a ten-percentage-point success decline, DeepSeek v2 still costs US$9,552.84 per month including Layer 3, below every other measured base case. Layer 3 scenarios of US$0, US$100, US$200, US$500 and US$1,000 add directly to monthly cost without changing the ranking. The lowest-token configuration, Qwen, needs 37.11% success to match Claude’s measured variable-plus-fallback cost, but achieved only 14.67%. Operational controls remain eight turns per run, a US$0.05 per-run tripwire and a US$3 member battery budget. No monthly per-user limit is implemented; 8,000 claims is planning volume, not a quota.
