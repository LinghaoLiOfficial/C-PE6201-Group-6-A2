# Total workspace

This is the compact, self-contained final workspace for the PE6201 A2 claim-agent implementation.

The canonical repository instructions, reproduction commands, result provenance, requirement map, and limitations are in the [root README](../README.md).

From this directory, run the complete offline reproduction with:

```bash
python3 run_all.py
```

The workspace contains the implementation in `agent_system/`, frozen evaluation material in `fixtures/`, tests in `tests/`, historical evidence in `results/`, and the reproducible cost model in `cost_model/`. Generated outputs are written to the ignored `artifacts/` directory.
